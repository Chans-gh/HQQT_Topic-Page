# 环球青藤专题页 Skill 分阶段迭代设计

日期：2026-11-17
状态：用户已确认按顺序实施

## 目标与边界

内部 `qingteng-topic-html` 继续承担环球青藤品牌专题页的内容整理、来源追溯、Web/H5 制作、验收与可选分享，不扩展成通用文件换肤工具。学员版“环球青藤·文件转网页”提供的价值主要是低门槛输入、页面方向推荐和快速预览；内部版只吸收这些交互优势，保留品牌组件、版本确认、事实边界与五层验收。

页面模式表示信息组织策略，不表示任意视觉皮肤。品牌页头、色板、字号、公共模板、组件契约和验收标准继续保持唯一来源。

## 版本顺序

### V1.9.1：分享安全收口

- 统一 Skill、package、provenance、组件目录和页头来源版本。
- 分享适配副本将放大图按钮安全降级为静态图片；原交付页保留放大。
- 上传前执行不需要密钥、不会上传的 preflight。
- doctor、工作流、质检文档和 Node 回归入口覆盖新增文件与行为。

### V2.0：页面模式路由与方向预览

在材料读取后、内容清单前形成结构化页面模式建议。固定候选为：报告阅读、课程教程、产品目录、运营说明、活动转化，另有 custom/uncertain 退路。语义判断只选择候选并给出概率或置信线索；组件映射、审批阶段与可执行动作由代码和记录契约决定。

状态至少包含页面目的、受众、主要材料类型、读者下一步、证据形态、内容规模与限制。输出记录推荐模式、备选模式、依据、风险、来源状态及用户决定。低置信或模式冲突时只提出建议，不自动生成 HTML。

内容清单确认后可生成两个轻量方向预览：同一品牌体系、同一已确认内容，只比较首屏和一个代表模块的组织方式。预览不生成新事实和素材，不产生用户确认；选择后再进入完整初稿。

### V2.1：长页面导航

- 增加真实锚点目录、返回开头和可选的多日/阶段切换索引。
- 导航只定位同一 DOM 中完整存在的内容，不分页、不隐藏必读章节。
- 移动端避免第二条吸顶栏遮挡内容；Day/阶段索引可横向浏览但保持键盘可达。

### V2.2：多格式输入记录

- 扩展输入记录为文本、飞书、Word、PDF、表格、网页、图片、视频等适配结果。
- 记录提取方式、实际读取范围、未读范围、结构损失、媒体/附件状态和失败原因。
- 宿主连接器负责读取；Skill 不伪装成自带所有解析器，也不把提取成功等同于事实核验。

### V2.3：产品目录与原文档查看模式

- 区分“内容重构”和“原件浏览”两种策略。
- 原件浏览用于商品册、作品集、资料目录等保留页序和原貌更重要的材料。
- 提供缩略索引、当前页状态、键盘/触屏导航与原件查看；不把普通长文强制做成文档播放器。

## 数据与错误处理

- 旧任务缺少新字段时继续可恢复，状态为 unknown/not-run，不追认历史推荐或用户选择。
- 页面模式建议与用户决定分开；推荐不能替代内容清单确认。
- 输入读取失败保持 unread，不猜内容；目录原件缺失时不能用占位截图冒充。
- 所有新增确定性规则进入 doctor/smoke/regression；语义效果用代表性材料前向测试，不能只匹配提示词。

## 验收策略

每个版本单独提交并保持可回退。V2.0 覆盖五种模式、冲突输入、低置信和自定义退路；V2.1 覆盖长目录、单章节、多日索引和 320–1440px；V2.2 覆盖读取成功、部分读取和失败；V2.3 覆盖 0/1/多页、键盘、触屏、原件缺失及内容重构退路。

Python 不可用的开发机只运行 Node 与静态检查，并明确标记 Python doctor/smoke 未执行；在可用环境补跑后才称完整回归通过。
