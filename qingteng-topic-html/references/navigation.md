# 长页目录与 Day/阶段导航

长页导航是内容索引，不是内容分页器。使用 `patterns.html#page-navigation` 或 `#stage-navigation`，将示意文案和 `href` 替换为真实模块名与锚点。

## 硬性约定

- 每个导航项使用真实 `href="#Mxx"`，目标 ID 在当前主体中唯一且存在。
- 目录不隐藏章节，不将 Day 做成只渲染当前页的 tab；搜索、打印和无脚本环境仍能连续阅读全部内容。
- 移动端 Day/阶段索引可局部横向浏览，但导航本身不吸顶，避免与 60px 官方页头叠加遮挡。
- 目标章节继续使用 86px `scroll-margin-top`。活动项的 `aria-current="location"` 只是阅读位置，不是完成状态。
- “返回开头”同样指向真实锚点，不写空链接或 JavaScript URL。

## 选择时机

报告、运营说明和长目录默认优先章节目录；课程或多阶段学习页可用 Day/阶段索引。短页、少量模块或目录本身会比内容更重时直接省略。
