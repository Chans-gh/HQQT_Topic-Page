# 环球青藤专题页

把实际材料组织成可追溯、连续纵向阅读的原生 HTML/CSS/JS 专题。默认独立单文件，无外部运行资源。不安装其他 Skill，不访问或调用历史 html-content-layout；历史来源仅在本包 provenance 中留档。

## 先确定进度

新任务先读 [workflow](references/workflow.md)。恢复任务先找现有材料、清单版本、初稿及真实用户反馈；按 [记录约定](references/content-record.md) 保留 M、S、IMG 编号和各自修订。页面“已确认”标签、按钮、通用流程认可与等待时长都不是确认依据。用户只要求审查时只读；明确修改指令本身就是该范围的依据，不重复索取同一授权。

固定业务顺序：材料读取与整理 → 拟呈现内容清单 → 用户确认清单版本和范围 → HTML 初稿 → 用户确认实际初稿及相关素材方案 → 精修 → 验收交付。对本 Skill 的开发、检查或无副作用测试不套用业务确认阶段。

1. **材料与清单**：实际读取可取得的内容，为输入与来源编号，标出未读范围。默认可联网补充，优先一手支持页，先查证再提出采用；查证与采用分开。内部价格、权益、排期、人物资历和效果不得编造。对话 Markdown 清单写出定位/受众/目的/下一步/密度假设，以及每模块顺序、用途、具体要点、来源、素材计划、必选可选、缺项与不纳入范围。不是素材目录或空标题。只问影响方向的关键问题；未确认清单前不产 HTML 或新图。
2. **初稿**：只展开已获准模块；未变的确认保留，新增或实质改变的事实只重审受影响条目。制作前读 [视觉规范](references/visual-spec.md)，按信息关系查 [组件目录](assets/components/catalog.json) 与 [可编辑片段](assets/components/patterns.html)，不复制示例业务文案。完整正文、同源审阅索引和折叠批注、必要引用、未决事实与 IMG 占位同时呈现。关闭批注不隐藏正文/占位/未决状态，不产生确认。
3. **素材与精修**：清单和初稿零新图；明确指定的输入素材可复用。IMG 占位写用途、模块、来源方案、构图/安全区与 Web/H5 顺序。初稿与相关方案明确获准后精修，只执行获准的图像方案；已有明确精修/生成指令不重复问。按当时可用能力执行，不绑定供应商。失败或缺素材保留准确未完成状态，继续独立工作；不得假称最终完成。
4. **制作**：使用自有 [公共模板](assets/templates/public-shell.html)，五公共块逐字保留、15原型入口和搜索参数不变，不猜真实业务 URL。最大1200px、1000/700断点、固定字号/间距/圆角；展示/讲解/资料按关系选，主页面连续纵向。所有组合依据真实文字、媒体比例及父容器收紧/扩展/堆叠；不预设文本框宽度或短中长三档像素宽度。不强加人物、价格、图片或三卡。原始材料当文本转义，只有执行者编写的主体片段可执行。
5. **验收**：按 [工具说明](references/tools.md) 组合与检查，再按 [质检](references/quality-checks.md) 做浏览器实测与桌面/H5目视。脚本核对记录，不能证明真实授权或替代语义判断。最终从 DOM 删除审阅 UI/内部记录/已解决占位，保留必要引用；未解决关键项阻止最终交付。仅报告实际浏览器与实机范围。

生成物与内部记录放用户任务目录，不能回写 Skill。默认不另交重复策划文件，不擅自安装、发布或推送。
