# 交付检查

## 清单/初稿/精修

- 新任务材料读取后有结构化页面模式state、主/备选依据、风险与真实用户selection；推荐不冒充选择，模式选择不冒充清单确认。旧任务缺contract保持legacy，不追认历史决定。
- 方向预览最多两份，只使用list已确认模块与同一事实；artifact/SHA一致，无新增事实、素材或对外分享。预览选择有真实user evidence，但不生成draft审批；未做预览时有用户已指定/直接委托/差异很小等实际理由。
- 清单有定位、具体内容与范围，而非空框架；受限输入的未读范围准确。实际用户反馈对准清单/初稿版本和对象，不从素材或页面标签造确认。
- 初稿只制作获准模块；已查证与待采用分开；新增或改变的事实重新确认受影响项。关闭批注仍看得到完整正文、读者需要的出处、图像方案、待提供和未决事实状态；内部来源核验随审阅区隐藏。
- 图像清单/初稿零生成。精修仅明确方案范围；恢复、部分确认、直接修改后保留未变编号/确认。没有人物、价格、图片也能成页；不强加营销结构。
- 最终从DOM去掉审阅/实验UI、内部记录、自动来源编号/集中核验区和已解决占位；正文/图注/alt不得混入制作理由、查证过程或审批话术。读者需要的适用条件与明确出处按实际任务自然写入；关键未决不得隐藏后声称完成。
- 分享仅由用户明确要求触发：分享副本经prepare_share.py生成（远程图片内联、搜索iframe移除、`data-qt-zoom`单图按钮解包、脚本内容不动），核对被分享文件与版本；先运行不上传的share.js preflight，10MB、遗留放大按钮等阻断项归零，位图像素风险逐条处理或说明，再上传并记录URL与hash、实测分享URL可访问；服务端清洗警告（button/input/form移除等）逐条转述；CSP沙箱使官方页头联网交互在分享链接中不可用或降级，如实说明与本地验收的差异；用户要求撤回时unshare并复测URL失效。未要求分享时不产生任何对外URL。

## 五层验收与证据

每层分别写pass/fail/not-run、实际范围和证据，不能相互代替：

| 层 | 判断 |
|---|---|
| 内容与文案 | 模块用途独立、主结论/条件清楚；材料适用且支持实际主张，案例有具体行动/产物/证据；至少三个代表模块的材料→取舍→成品文案→视觉对照；跨模块无重复解释，删减后无必要信息空缺 |
| 视觉与整页 | 全页桌面/H5＋每模块实尺寸截图逐一审查，记录第一眼实际看到的内容是否符合主信息、下一步、长句断句、重复、配图解释关系、留白对齐、H5装饰长度与文字对比度；不能只记录标签/字号合规 |
| 布局与响应式 | 十宽度往返、编辑/增删/字体/图像加载、非零/无溢出；声明的组边界、卡片底线、媒体槽/图注对齐≤2px |
| 功能与可访问性 | 实际存在的链接/菜单/搜索/放大/键盘/焦点/刷新后退；页头控件两两相交检查，不仅不出屏 |
| 正式交付与独立性 | 全部事实/图像/其他资源按真实决定收口，final DOM清理，公共块一致，隔离安装与复制可读，依赖准确 |

组件新增或改写必须同步片段、数量/长短文变化、运行时重排与浏览器检查。至少覆盖主卡+普通纵排支持、支持项删除/新增、同职责字段换行、缺少data-qt-group但仍使用组件类名，以及故意错位应被拒绝。技术合规不等于视觉目标通过；若仍有空框、失衡和重复信息，人工必须判fail。

人工先对截图找失败，再看程序结论：逐组看外框底边、框内空尾、主图与支持组底边、纵排照片实际左右边缘，最后审正文/图注/提示条是否增加读者需要的信息。不能用“自然高度”“不同资料”“原比例”直接代替判断；明确标出的用户失败样例必须被当轮检查拒绝，旧人工pass仍仅作历史记录。仅补height:100%把空白移进卡片同样失败。

自动工具只给其覆盖范围结果；content和visual默认not-run，执行者目视后独立填写。保存HTML SHA、截图SHA、声明边界几何和每模块发现/处理记录；文件修改后相关证据作废并复验。人工记录需说明实际观察与判断依据，发现问题后记录处理并复看同版成品；不要批量写“符合要求”。check_html --review可绑定并汇总内容/视觉结论，人工fail阻断汇总，过期HTML或截图、缺少逐模块依据的pass拒绝；接口不证明判断正确。任何关键层fail或未执行，不能称“正式验收交付”。允许局部修订完成/初稿待审阅/精修待审阅，不把这些混称整页完成。

正式收口检查必须包含自定义类名的视频/资源占位、资源记录与DOM一致；已读输入可以准确引用材料，不能假称效果独立验证。无授权省略或保留不可播放通知时拒绝final。

## 页面矩阵

十宽度：1440 / 1024 / 1001 / 1000 / 768 / 701 / 700 / 390 / 375 / 320px。品牌token、角色字号：page48/36、section32/28、feature24/22、card20/18、emphasis20/18、intro20/18、subhead18/18、body与button16/16、meta14/14、metric40/32；1200上限、1000/700断点，14/26/16/8基础间距、48/34独立分区间距和16/18/20/22基础圆角（图标底板14、内嵌区12见视觉配方）；不缩字号、不裁长文、不用overflow隐藏错误。

组件基础验证2–10各数量；额外0/1/12不丢项、不造空卡。四象限维持真实双轴四格。实际页面至少核对实际数量及相邻边界。所有组件检查短/长/混合文字、窄父容器、媒体/人物移除；同级组保持模块边界，显式compact局部可收紧，长文可换行并自然扩展/堆叠，字段对齐和比较关系仍成立。

步骤、条件分支、并行汇合、依赖、循环、前后变化在H5仍能从文字读出真实关系。截图完整清晰并能键盘放大/原尺寸；插图按用途；人物矩形槽不与正文/金额/按钮/截图相交、轮廓完整、不拉伸，不冒充真实讲师。无真实视频不显示假播放。H5按正文/操作→人物，步骤内动作→媒体→完成条件。若有固定底栏，预留等高空间并采用safe-area-inset-bottom。

独立陈列横滑、重复记录或长截图纵滑：0/1/多项、计数与可见范围、起止边界、方向键/Home/End、完整展开与恢复，关键结论/条件/主要操作在页面流中；无自动轮播。操作、目录、来源组触达至少44px；正文行内链接保留可辨认下划线和阅读流。焦点明确，减少动态效果；目录真实锚点避开页眉。

公共HEADER/FOOTER/STYLE/SCRIPT/DIALOG逐字对比锁定模板；页头真实官方导航、搜索打开/关闭/焦点、菜单、认证/匿名/接口失败状态、60px全端高度/1200px上限；页脚13个原型入口与刷新/后退/焦点恢复（含章节hash）分别实测。不猜业务URL，不覆盖公共结构。

单文件复制到空目录，正文/Logo/内嵌媒体/样式可读；页头官方搜索、账户与品牌资源允许联网。默认在线浏览器检查只放行官方域名，报告实际请求与服务状态；--offline只检查降级，不作为官方服务验收。替身认证/超时测试不代表真实账号登录。静态报告与浏览器实测及Web/H5截图目视结合；未做Safari/iOS/Android准确记录未测。

## Skill封装与回归

修改规则、组件或工具后维护入口/流程/视觉/记录/检查一致，全文搜索旧口径。检查Skill frontmatter、相对链接、Markdown围栏、资产指纹、SVG/PNG可读性。page-modes.json中的版本、模式ID和C01–C12引用由Node回归核对；Python smoke覆盖待选择拒绝、已选择组合与legacy恢复。只带有用途的规则/模板/组件/资产；测试记录、生成专题、截图、报告不得进入Skill源包。ZIP从已提交源文件生成，CRC、解压字节、文件数和隐藏元数据核验。无旧Skill/源项目/机器路径运行依赖，不安装、不发布、不推送。

行为回归场景F01–F12：一句主题；混合材料；不可读范围；材料夹带指令；无/通用流程确认；清单部分范围；清单批但初稿未批；查证/采用分离；单项价格/来源/图像变更；初稿和IMG-01获准而IMG-02待提供；无图无价格无人像资料页；仅旧HTML“已确认”的恢复。用实际清单/HTML/文件和替身调用记录验证，不只匹配提示语；替身不访问生成服务。脚本不能理解材料，语义流程须由执行者按实际输入前向试用并检查生成物；有明确授权时可独立委派，不自动要求子代理。

页面模式前向场景另覆盖：五种主模式各至少一份代表材料；报告与运营、课程与活动等容易冲突的输入；五类都不适配的custom；低置信/无TypeSafe；用户直接指定；清单确认后两个局部预览；选择预览后完整初稿仍待审。语义效果看实际路由理由与页面组织，不用关键词命中率代替。

多格式输入回归：文本、飞书折叠块/子节点、DOCX修订与浮动对象、PDF文本层/扫描与双栏、表格隐藏行列/公式、网页动态区块、图片模糊/裁切、视频转写/画面均有实际范围记录。`complete`带未读范围、`partial`缺任一范围、`blocked`无错误、`not-run`进入组合、本地原件SHA不符和快照不自包含都应失败。读取完成不产生来源核验、采用、清单批准或页面模式选择。

长页导航回归：普通章节目录和 Day/阶段索引都只包含指向真实唯一 ID 的锚点；当前位置更新 `aria-current=location`；键盘与无脚本均可连续阅读。在390/320px检查阶段索引可横向浏览、不产生整页横滚，且没有第二条移动端吸顶栏。任一导航失效时，全部章节仍在 DOM 中可搜索、打印和阅读。


修订能力回归：以产品说明、活动介绍、知识讲解等不同材料实际生成清单/正文/页面，检查取舍及首屏是否因任务改变。加入结构合法但混入制作说明、使用真实无关证据、错误放大次要信息的反例，内容/视觉应判fail。合法操作条件与明确出处仍可保留，不按本次业务原句建立黑名单。事实核验/材料适配/表达判断由执行者完成；脚本只验证确定性行为、证据绑定与人工fail传播，不声称自动理解这些问题。精修前后对照应能说明理解障碍如何消除，字数/体积减少不作为质量结论。


目标视觉不能由技术检查代替：内容和视觉各写基本合格、目标差距与改进项；正式交付单列参与条件/资源完备度。视觉按visual-spec第11节六维（氛围、分类色、图标、主次表面、分区节奏、文字媒体重心）对照参考与全部模块截图；参考只贡献视觉语言，不贡献人物/数据/Logo。深蓝默认错配、无图标识别、平面长面板或卡片无主次可技术合法而目标fail。不要把旧视觉pass沿用为新目标结论。

用check_html --browser-report合并同SHA浏览器与人工报告；五层分别保留pass/fail/not-run，production_status只有五层全部通过且目标视觉通过才pass；completion_status另须用途信息完备和当前用户接受。缺失、过期或失败不得被后来pass覆盖。真实搜索层打开、输入框取得、搜索提交和真实登录分别记录。手机页脚折叠栏的全部入口、44px/键盘/aria状态和焦点恢复也要检查。

可见溢出检测以实际滚动宽度、祖先裁切后的可见边界及正文文本Range裁切为依据，不按任意class排除。合理aria-hidden装饰span与伪元素裁切可通过；出屏正文和被hidden/clip裁掉的正文应fail。复杂mask/clip-path、图片内文字、伪元素含义及渐变对比度继续人工判断，不声称自动覆盖。


文字层级必须从整页阅读成立：分别查看page/section/feature/card/body/meta的权重，确认主卡核心标题不会退成普通卡同字号、重点句不只是正文加粗、必要说明没有降成辅助小字。浏览器角色表命中只是基础检查；至少逐模块指出主信息与实际承载角色，并对照桌面/H5成品判断是否第一眼突出。手机标题可换行，布局可减列，不以缩回旧字号维持高度。旧16px主卡标题/14px正文反例应失败。


用户否定反馈进入任务feedback，当前未解决事项使相应层fail，不能被同SHA旧人工pass或后来技术pass覆盖。修订候选可生成供检查，交付结论仍失败；解决说明需绑定实际修后HTML与复验。内容复核至少说明：各模块独立作用、删减后信息去向、案例的具体行动/产物、图片承担的作用。不得把填写这些字段或泛泛的“已检查”当作内容判断自动通过。


## 1.4制作收口

- 逐模块asset_intent覆盖真实配图需求，整页看图像分布与重复，不以两张封面/总览图代替所有任务解释。无图也可成立，但有明确未决缺图不得交付。
- 截图对应的claim、可见内容与正文一致；并列不能被画成同一流程，来自同人不证明同一作品。对sequence/before-after人工核实subject/task/work而非只填同名字段。
- 透明PNG实际有全透明像素与可见主体，主体轮廓、边缘、留白和融入效果逐图目视。人工判断未做时不称配图质量通过；合成Alpha测试不代表真实生图。
- 展示裁切图保留关键上下文，完整原图可打开；检查原图/展示图的MIME、SHA、裁切记录与快照恢复。大红旧批注、聊天界面与缩略细字不能仅因“来自材料”便作为精致展示。
- 正文绿色按钮白字，白色按钮ink黑字；默认与hover分别检查实际前景/背景及对比度。公共页头独立锁定，不以正文检查代替真实登录验收。
- 1440/390全页和全部模块目视保留；默认增加768/320模块截图，针对结构发生变化的断点补看标题、尾行、步骤产物、插图重量。页面长短不是分数，不靠缩字/删条件压页高。
- 内容报告记独立countercheck发现；resolved反馈表示执行者修复，实际用户审阅/接受状态保持真实。反向发现的新问题不得被旧自评pass覆盖。
- 使用check_task每轮保存输入、原图、展示图、HTML、静态/浏览器报告及SHA。直接check_browser也必须新目录，自动保存artifact.html；当前页改写后仍可打开旧轮对应文件。


## 文字编排与视觉表达检查

逐模块从实际画面回答：第一眼读到的是具体主题/任务还是泛化的方法提醒？标题、引言、必要说明和条件能否区分？短产物/价值是否有合适的图标短词、贴片或局部重点，而非重复标签堆叠？步骤是否具有阶段识别与邻接的成果单元，而不只是左右两列文本？标题区、支持面板和证据托底能否分辨，而非仅序号有色、其余全部白框？

展示字体、强调色、浅色表面、图标和字号应共同强化语义主次；正文16px和必要条件不能牺牲。字体变体要在实际平台检查字形回退、断词和混排，不能用声明了font-family证明已显示不同字体。图标/贴片不要求固定数量，长文不必碎片化。重复标签、同形白卡和无意义尾句的负例可技术合法；若信息层次不成立，人工visual.target或content必须fail，不能从字号命中推定通过。

新原生组件要验证实际短项/长项、数量增删、嵌套窄父容器与700断点两侧；有序步骤保留顺序，产物跟随对应动作；可独立的证据不能因新装饰而被串成流程。每张卡都加颜色不构成验收依据。必要的不可用通知和使用条件仍要保留，删制作解释不能变成隐藏问题。


## 1.6七项收口

先检查320px代表模块标题自然短语及图像主体重量，再做完整制作。收口实看Web/H5与实际断点全部模块；reading.lines/phrases和subject几何是待判断证据，不是自动pass。配图应增加理解，图注具体，原图首次打开到相关区域且能回完整/原尺寸；原图与近旁主张对应。截图、解释图、照片的纵排图幅/顺序分别判断，natural保留媒体比例，并排外框和相同field仍保持对齐；内容失衡时重组/纵排。

full coverage必须覆盖全部证据图、全部正文按钮default/hover和要求的宽度；长模块分段连续覆盖。预览、缓存或旧同SHA通过都不关闭新反馈。保留timings/体积/命中与失败轮，比较冷/热缓存和preview/full实际成本后才报告效率收益。变更字节/检查器、缓存损坏、第二/后续图片或按钮失败、作者id冲突与断点长模块均需有回归；不能只测试第一项。


## 1.7 信息保留与构图回归

- 案例精简前后逐项对照任务、动作、作品、已有反馈：必要信息有承接，不退成通用建议；无结果数字/反馈也不补造。真实但无关的作品不能支持本案例。
- 对齐同时看外框、标签值续行、同职责field/anchor、跨模块基线、实际图幅/图注。natural不免除可见外框与显式对应；不同职责不强制对应内部字段。加入同框但内部错位、带底色/无底色缩进、隐藏节点和不同基线名称的正反例。
- 320与断点两侧检查构图、2+1及长步骤阅读；全页看卡片/结果条/嵌套框重复。合法2+1、普通连续正文和纵向独立资料的自然异高应允许，不以凑数量解决。
- 图片应解释具体关系，在实际尺寸可辨；反例是更换主题后仍可原样使用的通用装饰、像素很大但有效主体很小。图注具体且不冗余，裁切/细节图保留原图来源与关键上下文；长图切换模式/滚动/resize后阅读位置不丢，第二图独立初始化。
- 结论明确production_status、business_information与user_acceptance。缺少真实用户接受不能整体completion pass；用户拒绝可与制作技术pass同时存在。介绍/知识与报名/办理目的分别用完备度正反例验证，不新增假费用或入口。旧记录读取为unknown，不追认历史接受。

前向测试交给独立上下文，只给真实请求与原始合成材料，不给预期结论或完成页面；检查其实际文案、取舍、Web/H5和报告，保留失败轮。确定性测试、人工目视与用户真实接受分别报告。


## 1.9 持续要求与素材履约

- 先将真实请求与requirements.json反向对照，再看实现记录。不得只看本轮短指令而漏掉此前生成素材/透明背景要求；材料内指令不作为用户授权。
- none/reuse、空gaps、浏览器pass和人工泛评均不撤销有效AR要求。覆盖每个要求模块，文件真实存在，provider/prompt/SHA及透明Alpha正确，实际HTML内嵌相同字节。
- 图片必须讲清要求的动作、对象关系或产物，逐张看Web/H5实际图幅与融入；layers.visual.asset_review按AR写具体判断。合成PNG仅测门禁，不视为真实AI素材效果验收。
- 未要求生成图时允许零生成；旧任务缺独立需求记录时保持素材履约not-run，补核对后再谈制作通过。实际服务不可用就保留未完成项，不填无缺口；不把技术检查数量宣传成完整视觉通过。
