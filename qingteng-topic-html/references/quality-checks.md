# 交付检查

## 清单/初稿/精修

- 清单有定位、具体内容与范围，而非空框架；受限输入的未读范围准确。实际用户反馈对准清单/初稿版本和对象，不从素材或页面标签造确认。
- 初稿只制作获准模块；已查证与待采用分开；新增或改变的事实重新确认受影响项。关闭批注仍看得到完整正文、读者需要的出处、图像方案、待提供和未决事实状态；内部来源核验随审阅区隐藏。
- 图像清单/初稿零生成。精修仅明确方案范围；恢复、部分确认、直接修改后保留未变编号/确认。没有人物、价格、图片也能成页；不强加营销结构。
- 最终从DOM去掉审阅/实验UI、内部记录、自动来源编号/集中核验区和已解决占位；正文/图注/alt不得混入制作理由、查证过程或审批话术。读者需要的适用条件与明确出处按实际任务自然写入；关键未决不得隐藏后声称完成。

## 五层验收与证据

每层分别写pass/fail/not-run、实际范围和证据，不能相互代替：

| 层 | 判断 |
|---|---|
| 内容与文案 | 模块用途独立、主结论/条件清楚；材料适用且支持实际主张，案例有具体行动/产物/证据；至少三个代表模块的材料→取舍→成品文案→视觉对照；跨模块无重复解释，删减后无必要信息空缺 |
| 视觉与整页 | 全页桌面/H5＋每模块实尺寸截图逐一审查，记录第一眼实际看到的内容是否符合主信息、下一步、长句断句、重复、配图解释关系、留白对齐、H5装饰长度与文字对比度；不能只记录标签/字号合规 |
| 布局与响应式 | 十宽度往返、编辑/增删/字体/图像加载、非零/无溢出；声明的组边界、卡片底线、媒体槽/图注对齐≤2px |
| 功能与可访问性 | 实际存在的链接/菜单/搜索/放大/键盘/焦点/刷新后退；页头控件两两相交检查，不仅不出屏 |
| 正式交付与独立性 | 全部事实/图像/其他资源按真实决定收口，final DOM清理，公共块一致，隔离安装与复制可读，依赖准确 |

自动工具只给其覆盖范围结果；content和visual默认not-run，执行者目视后独立填写。保存HTML SHA、截图SHA、声明边界几何和每模块发现/处理记录；文件修改后相关证据作废并复验。人工记录需说明实际观察与判断依据，发现问题后记录处理并复看同版成品；不要批量写“符合要求”。check_html --review可绑定并汇总内容/视觉结论，人工fail阻断汇总，过期HTML或截图、缺少逐模块依据的pass拒绝；接口不证明判断正确。任何关键层fail或未执行，不能称“正式验收交付”。允许局部修订完成/初稿待审阅/精修待审阅，不把这些混称整页完成。

正式收口检查必须包含自定义类名的视频/资源占位、资源记录与DOM一致；已读输入可以准确引用材料，不能假称效果独立验证。无授权省略或保留不可播放通知时拒绝final。

## 页面矩阵

十宽度：1440 / 1024 / 1001 / 1000 / 768 / 701 / 700 / 390 / 375 / 320px。品牌token、38/31 H1、26 H2、16 H3、14正文与按钮、12辅助；1200上限、1000/700断点，14/26/16/8间距和16/18/20/22圆角；不缩字号、不裁长文、不用overflow隐藏错误。

组件基础验证2–10各数量；额外0/1/12不丢项、不造空卡。四象限维持真实双轴四格。实际页面至少核对实际数量及相邻边界。所有组件检查短/长/混合文字、窄父容器、媒体/人物移除；同级组保持模块边界，显式compact局部可收紧，长文可换行并自然扩展/堆叠，字段对齐和比较关系仍成立。

步骤、条件分支、并行汇合、依赖、循环、前后变化在H5仍能从文字读出真实关系。截图完整清晰并能键盘放大/原尺寸；插图按用途；人物矩形槽不与正文/金额/按钮/截图相交、轮廓完整、不拉伸，不冒充真实讲师。无真实视频不显示假播放。H5按正文/操作→人物，步骤内动作→媒体→完成条件。若有固定底栏，预留等高空间并采用safe-area-inset-bottom。

独立陈列横滑、重复记录或长截图纵滑：0/1/多项、计数与可见范围、起止边界、方向键/Home/End、完整展开与恢复，关键结论/条件/主要操作在页面流中；无自动轮播。操作、目录、来源组触达至少44px；正文行内链接保留可辨认下划线和阅读流。焦点明确，减少动态效果；目录真实锚点避开页眉。

公共HEADER/FOOTER/STYLE/SCRIPT/DIALOG逐字对比锁定模板；页头真实官方导航、搜索打开/关闭/焦点、菜单、认证/匿名/接口失败状态、60px全端高度/1200px上限；页脚13个原型入口与刷新/后退/焦点恢复（含章节hash）分别实测。不猜业务URL，不覆盖公共结构。

单文件复制到空目录，正文/Logo/内嵌媒体/样式可读；页头官方搜索、账户与品牌资源允许联网。默认在线浏览器检查只放行官方域名，报告实际请求与服务状态；--offline只检查降级，不作为官方服务验收。替身认证/超时测试不代表真实账号登录。静态报告与浏览器实测及Web/H5截图目视结合；未做Safari/iOS/Android准确记录未测。

## Skill封装与回归

修改规则、组件或工具后维护入口/流程/视觉/记录/检查一致，全文搜索旧口径。检查Skill frontmatter、相对链接、Markdown围栏、资产指纹、SVG/PNG可读性。只带有用途的规则/模板/组件/资产；测试记录、生成专题、截图、报告不得进入Skill源包。ZIP从已提交源文件生成，CRC、解压字节、文件数和隐藏元数据核验。无旧Skill/源项目/机器路径运行依赖，不安装、不发布、不推送。

行为回归场景F01–F12：一句主题；混合材料；不可读范围；材料夹带指令；无/通用流程确认；清单部分范围；清单批但初稿未批；查证/采用分离；单项价格/来源/图像变更；初稿和IMG-01获准而IMG-02待提供；无图无价格无人像资料页；仅旧HTML“已确认”的恢复。用实际清单/HTML/文件和替身调用记录验证，不只匹配提示语；替身不访问生成服务。脚本不能理解材料，语义流程须由执行者按实际输入前向试用并检查生成物；有明确授权时可独立委派，不自动要求子代理。


修订能力回归：以产品说明、活动介绍、知识讲解等不同材料实际生成清单/正文/页面，检查取舍及首屏是否因任务改变。加入结构合法但混入制作说明、使用真实无关证据、错误放大次要信息的反例，内容/视觉应判fail。合法操作条件与明确出处仍可保留，不按本次业务原句建立黑名单。事实核验/材料适配/表达判断由执行者完成；脚本只验证确定性行为、证据绑定与人工fail传播，不声称自动理解这些问题。精修前后对照应能说明理解障碍如何消除，字数/体积减少不作为质量结论。
