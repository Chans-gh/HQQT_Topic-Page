# 交付检查

## 清单/初稿/精修

- 清单有定位、具体内容与范围，而非空框架；受限输入的未读范围准确。实际用户反馈对准清单/初稿版本和对象，不从素材或页面标签造确认。
- 初稿只制作获准模块；已查证与待采用分开；新增或改变的事实重新确认受影响项。关闭批注仍看得到完整正文、必要引用、图像方案、待提供和未决事实状态。
- 图像清单/初稿零生成。精修仅明确方案范围；恢复、部分确认、直接修改后保留未变编号/确认。没有人物、价格、图片也能成页；不强加营销结构。
- 最终从DOM去掉审阅/实验UI、内部记录和已解决占位，必要引用保留；关键未决不得隐藏后声称完成。

## 页面矩阵

十宽度：1440 / 1024 / 1001 / 1000 / 768 / 701 / 700 / 390 / 375 / 320px。品牌token、38/31 H1、26 H2、16 H3、14正文与按钮、12辅助；1200上限、1000/700断点，14/26/16/8间距和16/18/20/22圆角；不缩字号、不裁长文、不用overflow隐藏错误。

组件基础验证2–10各数量；额外0/1/12不丢项、不造空卡。四象限维持真实双轴四格。实际页面至少核对实际数量及相邻边界。所有组件检查短/长/混合文字、窄父容器、媒体/人物移除；短文收紧整个组合，长文自然扩展/堆叠，字段对齐和比较关系仍成立。

步骤、条件分支、并行汇合、依赖、循环、前后变化在H5仍能从文字读出真实关系。截图完整清晰并能键盘放大/原尺寸；插图按用途；人物矩形槽不与正文/金额/按钮/截图相交、轮廓完整、不拉伸，不冒充真实讲师。无真实视频不显示假播放。H5按正文/操作→人物，步骤内动作→媒体→完成条件。若有固定底栏，预留等高空间并采用safe-area-inset-bottom。

独立陈列横滑、重复记录或长截图纵滑：0/1/多项、计数与可见范围、起止边界、方向键/Home/End、完整展开与恢复，关键结论/条件/主要操作在页面流中；无自动轮播。触达至少44px，焦点明确，减少动态效果；目录真实锚点避开页眉。

公共HEADER/FOOTER/STYLE/SCRIPT/DIALOG逐字对比锁定模板；页头真实官方导航、搜索打开/关闭/焦点、菜单、认证/匿名/接口失败状态、60px全端高度/1200px上限；页脚13个原型入口与刷新/后退/焦点恢复（含章节hash）分别实测。不猜业务URL，不覆盖公共结构。

单文件复制到空目录，正文/Logo/内嵌媒体/样式可读；页头官方搜索、账户与品牌资源允许联网。默认在线浏览器检查只放行官方域名，报告实际请求与服务状态；--offline只检查降级，不作为官方服务验收。替身认证/超时测试不代表真实账号登录。静态报告与浏览器实测及Web/H5截图目视结合；未做Safari/iOS/Android准确记录未测。

## Skill封装与回归

修改规则、组件或工具后维护入口/流程/视觉/记录/检查一致，全文搜索旧口径。检查Skill frontmatter、相对链接、Markdown围栏、资产指纹、SVG/PNG可读性。只带有用途的规则/模板/组件/资产；测试记录、生成专题、截图、报告不得进入Skill源包。ZIP从已提交源文件生成，CRC、解压字节、文件数和隐藏元数据核验。无旧Skill/源项目/机器路径运行依赖，不安装、不发布、不推送。

行为回归场景F01–F12：一句主题；混合材料；不可读范围；材料夹带指令；无/通用流程确认；清单部分范围；清单批但初稿未批；查证/采用分离；单项价格/来源/图像变更；初稿和IMG-01获准而IMG-02待提供；无图无价格无人像资料页；仅旧HTML“已确认”的恢复。用实际清单/HTML/文件和替身调用记录验证，不只匹配提示语；替身不访问生成服务。脚本不能理解材料，语义流程须由独立执行者按真实请求前向试用并检查生成物。
